# JCB Rental — Heavy UI

This folder is reserved for the contents of `heavy-equipment-rental-ui.zip`.

## Before merging
- Extract the ZIP contents here (not the ZIP itself).
- Copy the nine images from `public/images/` into `src/assets/`: `backhoe.jpg`, `crane.jpg`, `dozer.jpg`, `excavator.jpg`, `hero.jpg`, `loader.jpg`, `mini.jpg`, `roller.jpg`, `telehandler.jpg`.
- Confirm `npm install` and `npm run build` succeed.

Vercel settings: Root Directory `ui-heavy`, Framework `Vite`, Install `npm install`, Build `npm run build`, Output `dist`.
