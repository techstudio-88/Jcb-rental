# JCB Rental — Mobile UI

This folder is reserved for the contents of `equipment-rental-mobile-ui.zip`.

## Before merging
- Extract the ZIP contents here (not the ZIP itself).
- Copy the six images from `public/images/` into `src/assets/`: `excavator-sunset.jpg`, `hero-excavator.jpg`, `backhoe.jpg`, `bulldozer.jpg`, `crane.jpg`, `loader.jpg`.
- Keep `DEMO_MODE = true` in `src/store.ts` until real authentication and backend integration are implemented.
- Confirm `npm install` and `npm run build` succeed.

Vercel settings: Root Directory `ui-mobile`, Framework `Vite`, Install `npm install`, Build `npm run build`, Output `dist`.
